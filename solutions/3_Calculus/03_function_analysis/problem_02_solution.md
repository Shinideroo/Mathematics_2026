### Problem 2. A Parabola from the Perspective of the Derivative
For $f(x)=x^2-4x+1$, find the minimum using the derivative. Compare the result with the vertex form and explain why both approaches lead to the same point.

> **Why this problem:** it connects a new tool with the familiar geometry of a parabola.

## Solution

Differentiate:

$$
f'(x)=2x-4=2(x-2).
$$

It is negative for $x<2$ and positive for $x>2$, so the function decreases then increases. Its unique global minimum is

$$
f(2)=4-8+1=-3,
\qquad \text{at }(2,-3).
$$

Completing the square independently gives $f(x)=(x-2)^2-3$. Since the square is nonnegative and is zero only at $x=2$, this verifies both the location and value of the minimum. Both methods describe the same upward parabola: its vertex is where its tangent slope changes from negative to positive.
